# Algorithms

Searching and sorting in Java, based on [Java Exercises – GeeksforGeeks](https://www.geeksforgeeks.org/java/java-exercises/) (GfG exercises 24–30, numbered `01`–`07` here).

| Exercise | GfG # | Algorithm |
|---|---|---|
| `01` | 24 | Linear search |
| `02` | 25 | Binary search |
| `03` | 26 | Bubble sort |
| `04` | 27 | Insertion sort |
| `05` | 28 | Selection sort |
| `06` | 29 | Merge sort |
| `07` | 30 | Quick sort |

Location: `src/main/java/com/ejercicios/algoritmos/`. Requires JDK 21 and Maven (`mvn compile`).
