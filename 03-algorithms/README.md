# Algorithms

Searching and sorting in Java, based on [Java Exercises – GeeksforGeeks](https://www.geeksforgeeks.org/java/java-exercises/) (exercises 24–30).

| Exercise | Algorithm |
|---|---|
| 24 | Linear search |
| 25 | Binary search |
| 26 | Bubble sort |
| 27 | Insertion sort |
| 28 | Selection sort |
| 29 | Merge sort |
| 30 | Quick sort |

Location: `src/main/java/com/ejercicios/algoritmos/`. Requires JDK 21 and Maven (`mvn compile`).
