# Algorithms

Búsqueda y ordenamiento en Java, a partir de [Java Exercises – GeeksforGeeks](https://www.geeksforgeeks.org/java/java-exercises/) (ejercicios 24–30).

| Ejercicio | Algoritmo |
|---|---|
| 24 | Búsqueda lineal |
| 25 | Búsqueda binaria |
| 26 | Bubble sort |
| 27 | Insertion sort |
| 28 | Selection sort |
| 29 | Merge sort |
| 30 | Quick sort |

Ubicación: `src/main/java/com/ejercicios/algoritmos/`. Requiere JDK 21 y Maven (`mvn compile`).
