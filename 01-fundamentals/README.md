# Fundamentals

Language basics: syntax, control flow and basic data types.
**Scope:** no class design. That goes in [`02-oop`](../02-oop/); algorithms go in [`03-algorithms`](../03-algorithms/).

| Module | Contents |
|---|---|
| `01-basics` | Core concepts (exercises 1–8) |
| `02-loops` | Nested loops and patterns (9–13) |
| `03-arrays` | Arrays (14–19) |
| `04-strings` | Strings (20–23) |

The exercises come from [Java Exercises – GeeksforGeeks](https://www.geeksforgeeks.org/java/java-exercises/); the problem statements are on the original page.

Planned: collections, generics, exceptions, I/O, streams.

Build: `mvn compile`
