# Fundamentals

Base del lenguaje Java: sintaxis, control de flujo y tipos de datos básicos.
**Límite:** nada de diseño de clases. Eso va en [`oop`](../02-oop/); los algoritmos, en [`algorithms`](../03-algorithms/).

| Módulo | Contenido |
|---|---|
| `01-basics` | Conceptos básicos (ejercicios 1–8) |
| `02-loops` | Bucles anidados y patrones (9–13) |
| `03-arrays` | Arrays (14–19) |
| `04-strings` | Strings (20–23) |

Los ejercicios vienen de [Java Exercises – GeeksforGeeks](https://www.geeksforgeeks.org/java/java-exercises/); los enunciados están en la página original.

A futuro: collections, generics, excepciones, I/O, streams.

Compilar: `mvn compile`
